# LaTeX to Equation Converter

A simple web application built with React, TypeScript, Vite, and Tailwind CSS that converts LaTeX mathematical notation into beautifully rendered equations using the KaTeX library. Features live preview and dark mode support.

## Features

- **Live LaTeX Rendering:** Instantly see your LaTeX code rendered as a mathematical equation.
- **KaTeX Integration:** Utilizes the fast and easy-to-use KaTeX library for high-quality math typesetting.
- **Dark Mode:** Switch between light and dark themes for comfortable viewing.
- **Copy Functionality:** Easily copy the LaTeX input or the rendered equation (implementation details might vary).
- **Responsive Design:** Adapts to different screen sizes.

## Tech Stack

- **Frontend:** React, TypeScript
- **Build Tool:** Vite
- **Styling:** Tailwind CSS
- **LaTeX Rendering:** KaTeX

## Getting Started

Follow these instructions to get a copy of the project up and running on your local machine for development and testing purposes.

### Prerequisites

- Node.js (v20 or later recommended)
- npm

### Installation

1.  Clone the repository:
    ```bash
    git clone https://github.com/thisisdkyadav/latex-converter.git
    cd latex-converter
    ```
2.  Install NPM packages:
    ```bash
    npm install
    ```

### Running Locally

1.  Start the development server:
    ```bash
    npm run dev
    ```
2.  Open your browser and navigate to `http://localhost:5173` (or the port specified in the output).

## Usage

1.  Enter or paste your LaTeX code into the input field.
2.  The rendered equation will appear in the output area below.
3.  Use the toggle switch to change between light and dark modes.
4.  Use the action buttons (e.g., Copy LaTeX) as needed.

## Building for Production

```bash
npm run build
```

This command builds the app for production to the `dist` folder.
